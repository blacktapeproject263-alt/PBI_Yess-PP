# Документирование семантической модели Yess-PP

В активной модели отчета `Yess-PP.pbix` на данный момент отсутствует документация метаданных: ни одна из 10 бизнес-таблиц и 59 мер не содержит заполненного поля `Description`. 

Добавление описаний позволит:
- Улучшить понимание логики расчетов бизнес-пользователями и аналитиками (всплывающие подсказки при наведении в Power BI Desktop и Power BI Service).
- Облегчить поддержку и аудит DAX-вычислений.
- Подготовить модель к использованию AI/Copilot функций Fabric и Power BI Q&A.

## User Review Required

> [!IMPORTANT]
> Изменения будут внесены напрямую в активную модель отчета `Yess-PP.pbix` через сессию `PBIDesktop--50589` с использованием транзакций (`useTransaction: true`). Пожалуйста, подтвердите предложенные тексты описаний для таблиц и ключевых мер.

## Proposed Changes

### 1. Документирование таблиц (Table Descriptions)

С помощью инструмента `table_operations` (операция `Update`) будут добавлены описания к следующим бизнес-таблицам:

| Таблица | Предлагаемое описание |
| :--- | :--- |
| **`Sales`** | Таблица фактов фактических продаж товаров. Содержит строки чеков, даты, количество, цену за единицу, себестоимость, клиента и магазин. |
| **`SalesPlan`** | Таблица плановых показателей продаж в разрезе магазинов и дат. |
| **`Purchases`** | Таблица фактов закупки и перемещения товаров поставщиками по складам и магазинам. |
| **`OPEX`** | Таблица операционных расходов компании в разрезе дат, категорий и подкатегорий затрат. |
| **`Products`** | Справочник товаров (измерение): категория, подкатегория, бренд, цвет, производитель и весовая категория. |
| **`Stores`** | Справочник розничных магазинов (измерение): город, координаты, торговая площадь, штат продавцов и дата открытия. |
| **`dimCustomers`** | Справочник клиентов (измерение): пол, род занятий, дата рождения, возрастные группы и контакты. |
| **`Calendar`** | Вычисляемая таблица календаря для анализа временных рядов (Time Intelligence) и сопоставления факта с планом. |
| **`Operations`** | Фактические и плановые операционные расходы по магазинам и категориям затрат. |
| **`MeasureTable`** | Выделенная таблица для хранения сквозных расчетных мер (остатки, накопительные итоги, выбор валюты). |

### 2. Документирование ключевых мер (Measure Descriptions)

С помощью инструмента `measure_operations` (операция `Update`) будут заполнены описания для групп мер:

#### Таблица `Sales` (Основные финансовые и операционные показатели)

| Мера | Формула (кратко) | Предлагаемое описание |
| :--- | :--- | :--- |
| **`Sales`** | `SUMX(Sales, [Price $/each] * [Quantity])` | Общая выручка от продаж (рассчитанная построчно как цена умножить на количество). |
| **`4. Sales`** | `SUMX(Sales, [Price $/each] * [Quantity])` | Общая сумма фактических продаж в базовой валюте ($). |
| **`2. SalesQuantity`** | `SUM(Sales[Quantity])` | Общее количество проданных единиц товара. |
| **`1. CustomerCount`** | `DISTINCTCOUNT(Sales[CustomerID])` | Количество уникальных покупателей, совершивших покупки за выбранный период. |
| **`5.COGS`** | `SUMX(Sales, [Quantity] * [Cost of Goods])` | Себестоимость реализованной продукции (Cost of Goods Sold). |
| **`6.Margin`** | `[4. Sales] - [5.COGS]` | Валовая прибыль (маржа) в абсолютном выражении: выручка за вычетом себестоимости. |
| **`7.margin%`** | `[6.Margin] / [4. Sales]` | Рентабельность продаж (валовая маржа, %): отношение маржи к выручке. |
| **`8.Margin%`** | `(SalesTotal - COGS) / SalesTotal` | Альтернативный автономный расчет рентабельности продаж через переменные (VAR). |
| **`Sales - OPEX`** | `[Sales] - SUM(OPEX[OPEX])` | Операционная прибыль: выручка от продаж за вычетом операционных расходов (OPEX). |
| **`PlanFact%`** | `DIVIDE([4. Sales], [1.SalesPlan], 0)` | Процент выполнения плана продаж (отношение фактических продаж к плану). |
| **`x1.Ср Чек`** | `[4. Sales] / DISTINCTCOUNT(Sales[Receipt Number])` | Средний чек: выручка от продаж, деленная на количество уникальных чеков. |

#### Таблица `Sales` (Time Intelligence и сравнительный анализ)

| Мера | Формула (кратко) | Предлагаемое описание |
| :--- | :--- | :--- |
| **`91.salesPrevMonth`** | `CALCULATE([4. Sales], PREVIOUSMONTH('Calendar'[Date]))` | Выручка за предыдущий календарный месяц. |
| **`92.SalesSPLY`** | `CALCULATE([4. Sales], SAMEPERIODLASTYEAR('Calendar'[Date]))` | Выручка за аналогичный период прошлого года (Same Period Last Year). |
| **`93. Sales YTD`** | `CALCULATE([4. Sales], DATESYTD('Calendar'[Date]))` | Накопительные продажи с начала календарного года по текущую дату (Year-To-Date). |
| **`94. Sales FYTD`** | `CALCULATE([4. Sales], DATESYTD('Calendar'[Date], "6-30"))` | Накопительные продажи с начала финансового года (со смещением от 30 июня). |
| **`95. Sales2MonthAgo`** | `CALCULATE([4. Sales], DATEADD('Calendar'[Date], -2, MONTH))` | Продажи за период два месяца назад относительно текущего фильтра дат. |

#### Таблица `Sales` (Структурные и логистические метрики)

| Мера | Формула (кратко) | Предлагаемое описание |
| :--- | :--- | :--- |
| **`981. Sales Share`** | `DIVIDE([4. Sales], [97. Sales All], 0)` | Доля продаж выбранного товара или группы в общем объеме продаж компании. |
| **`982. Color Share in Category`** | `DIVIDE([4. Sales], [98.SalesAllColor], 0)` | Доля продаж конкретного цвета в объеме продаж категории товаров. |
| **`983.ShippedQuantity`** | `CALCULATE([2. SalesQuantity], USERELATIONSHIP(...Shipment date))` | Количество отгруженного товара с использованием альтернативной связи по дате отгрузки. |
| **`984. % Shipped`** | `DIVIDE([983.ShippedQuantity], [2. SalesQuantity], 0)` | Процент отгрузки: доля отгруженных единиц от общего проданного количества. |
| **`41. Sales KZT`** | `SUMX(..., [Price] * [Qty] * RELATED(Calendar[KZT]))` | Продажи в национальной валюте (тенге, KZT) по курсу на дату операции. |
| **`42. Sales Multicurrency`**| `IF(SELECTEDVALUE(...) = "$", [4. Sales], [41. Sales KZT])` | Мультивалютная выручка с динамическим переключением валюты отображения. |

#### Таблица `SalesPlan` (Планирование)

| Мера | Формула (кратко) | Предлагаемое описание |
| :--- | :--- | :--- |
| **`1.SalesPlan`** | `SUM(SalesPlan[Plan])` | Общий плановый объем продаж за выбранный период. |
| **`2. MinSalesPlan`** | `MIN(SalesPlan[Plan])` | Минимальное значение плана продаж среди выбранных срезов. |
| **`3. MaxSalesPlan`** | `MAX(SalesPlan[Plan])` | Максимальное значение плана продаж среди выбранных срезов. |
| **`4. AverageSalesPlan`**| `AVERAGE(SalesPlan[Plan])` | Средний плановый показатель продаж на период/магазин. |
| **`52.SalesPlanYTD`** | `CALCULATE([1.SalesPlan], DATESYTD(...))` | План продаж нарастающим итогом с начала года (YTD). |

#### Таблица `MeasureTable` (Остатки и складской учет)

| Мера | Формула (кратко) | Предлагаемое описание |
| :--- | :--- | :--- |
| **`Кол-во продаж накопительно`** | `CALCULATE([2. SalesQuantity], FILTER(ALL('Calendar'), <= MAX(Date)))` | Суммарное количество проданного товара нарастающим итогом на конец выбранного периода. |
| **`Кол-во закуплено накопительно`**| `CALCULATE([Purchase Quantity], FILTER(ALL('Calendar'), <= MAX(Date)))` | Суммарное количество закупленного товара нарастающим итогом на конец выбранного периода. |
| **`Остатки`** | `[Кол-во закуплено накопительно] - [Кол-во продаж накопительно]` | Расчетный товарный остаток на складах на дату среза (закупки минус продажи). |

#### Таблица `Operations` (Операционная деятельность)

| Мера | Формула (кратко) | Предлагаемое описание |
| :--- | :--- | :--- |
| **`1.ActualCost`** | `SUM(Operations[Actual Cost])` | Фактические операционные расходы магазинов. |
| **`2.PlannedCost`** | `SUM(Operations[Planned Cost])` | Плановые операционные расходы магазинов. |
| **`3.ActualCost%`** | `[1.ActualCost] / [2.PlannedCost]` | Процент освоения операционного бюджета (факт к плану). |
| **`4.NetMargin`** | `[4. Sales] - [5.COGS] - [1.ActualCost]` | Чистая маржа: валовая прибыль за вычетом операционных расходов. |
| **`5.MarginNet%`** | `[4.NetMargin] / [4. Sales]` | Чистая рентабельность продаж (%): отношение чистой маржи к выручке. |
